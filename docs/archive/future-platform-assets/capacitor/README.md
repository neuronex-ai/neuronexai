# Arquivo futuro — Capacitor

Este diretório preserva uma configuração antiga do Capacitor apenas como referência para uma eventual reconstrução nativa.

O aplicativo atual é web/PWA e não possui dependências, scripts ou projetos de plataforma Capacitor ativos. Agentes não devem reativar esta configuração nem usá-la como base da versão mobile sem autorização explícita de produto e uma nova auditoria técnica.
